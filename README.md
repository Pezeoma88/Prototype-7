# CarpoolBoard

**CarpoolBoard** is a mobile carpooling application designed for Southern Methodist University (SMU) students. The app helps students find rides, offer transportation, and coordinate pickup locations around campus.

Built with React Native, Expo, and Supabase, CarpoolBoard provides separate Driver and Rider experiences.

## Features

### Driver Features
- Create and post rides with destinations, departure dates, and times.
- Select pickup locations from SMU campus landmarks.
- Use GPS to suggest a nearby pickup location.
- Set the number of available seats.
- Edit or cancel existing rides.
- Manage incoming ride requests.

### Rider Features
- Browse available rides.
- View ride details, pickup locations, and departure information.
- Request available seats.
- View pickup locations on an interactive map.
- See a map preview of the pickup landmark in Ride Details.

### Additional Features
- **Driver/Rider Toggle:** Switch between modes without logging out.
- **First-Time Onboarding:** Three-step introduction with mode selection and optional profile setup.
- **Profile Management:** Edit profile information and receive confirmation after saving.
- **Interactive Map:** Explore pickup locations and routes.
- **Pickup Map Preview:** View a zoomed-in map of the selected pickup location.
